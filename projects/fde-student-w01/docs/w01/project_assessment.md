# W01 立项评估报告（提交版）

## 1. 本周目标与结论摘要

- 本周目标：基于标准产品 `0.2.0-w1` 的真实运行证据与首轮正式访谈，判断青禾项目是否具备进入下一阶段的条件。
- 当前结论：可以进入“继续核实并小范围验证”的下一阶段，但不具备直接承诺业务效果（如“三个月复购回升幅度”）的证据条件。
- 主要原因：
  1. 客户业务目标明确（复购止跌回升），但关键口径与范围未定；
  2. 标准产品在样例数据上的 11 个实时验证场景均通过，Promptfoo 的 7 个基础用例均通过；这只证明当前样例、模型配置和运行条件下的行为，不代表青禾真实数据已适配；
  3. 客户侧系统、数据、流程与审批条件尚未由对应角色完成核实。

## 2. 业务问题与诉求拆解

依据访谈记录（`artifacts/w01/W1-interview-1c80a6d9-7d6e-5625-8888-5dafe1e96c80-public.json`）与邮件语境，当前核心诉求为：

1. **业务目标诉求**：会员复购率止跌回升（方向明确，量化目标未定）。
2. **经营对象识别诉求**：在活跃会员中识别重点经营人群，并支持后续运营动作。
3. **运营流程诉求**：对接小林的日常运营流程，减少额外整理负担。
4. **时间预期诉求**：三个月内看到效果（属于管理期望，不等于可直接承诺结果）。
5. **接入落地诉求**：确认数据来源、口径、系统接入边界与审批流程。

## 5. 技术验证状态与风险

### 5.1 当前验证状态

- 当前归档的 `environment_check.json` 全部检查项均为 `pass`；`runtime_evidence.json` 的 11 个实时场景均通过。
- `promptfoo-results.json` 显示 7 个基础评估用例全部通过。评估与实时验证针对教学样例数据，不是青禾数据上的客户验收。
- 这些结果是当前模型、提示词、产品版本、样例数据与运行环境下的记录；更换模型/配置或修改代码后，应重新生成并核对相应证据。

### 5.2 主要风险

1. **模型稳定性风险**：本次日期文字/按钮选择场景均通过，但这是当前配置下的有限样本，模型输出可能波动；更换模型或配置后需重新回归。
2. **口径风险**：复购、活跃、分组定义未统一，后续验证可能出现“结论可读但口径不可比”。
3. **接入风险**：客户系统与数据权限边界不清，导致系统适配范围与成本无法准确估算。
4. **承诺风险**：若将角色表述直接写成交付承诺，存在明显超承诺风险。

## 6. 下一阶段建议（W02 起）

1. **开展多角色核实访谈**
   - 老周：数据口径、可用字段、更新频率、权限与接口条件；
   - 小林：当前运营流程、名单产出与执行闭环；
   - 王经理：预算、合同、审批边界与阶段目标。

2. **验证客户数据与流程适配**
   - 在取得授权和明确口径后，核对复购率、活跃会员、分组和数据覆盖定义；
   - 评估数据接入、权限、更新频率以及运营结果如何回写/核验；样例验证不能替代这些工作。

3. **用证据驱动修订 fit-gap**
   - 沿用现有 GAP 编号，不重写历史；
   - 对新增证据只更新受影响条目，保留未解决冲突与待判断项。

## 7. 承诺边界（本周）

- **可承诺**：已完成标准产品在样例数据上的阶段性实时验证与基础评估，并形成可追溯证据链和初步 fit-gap 判断。
- **暂不承诺**：
  - 不承诺“三个月内达成具体复购提升幅度”；
  - 不承诺已完成青禾真实数据接入；
  - 不承诺运营流程已在客户现场闭环落地。
